# Aljunaid Admin Dashboard

Admin dashboard for Aljunaid Educational Platform built with React, Vite, TypeScript, and Tailwind CSS.

---

## Overview

Aljunaid Admin Dashboard is a modern educational content management system (CMS) designed for managing:

- Courses
- Lessons
- Educational Content
- Quizzes
- Publishing Workflows

The dashboard is part of the Aljunaid Educational Platform ecosystem.

---

## Features

- Authentication System
- Course Management
- Lesson Management
- Content Upload System
- Quiz Builder
- Lesson Publishing Workflow
- Validation & Error Handling
- Responsive Admin Dashboard
- Arabic RTL Interface

---

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
